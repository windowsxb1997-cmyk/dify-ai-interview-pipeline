# 需求确认书：AI 用户访谈流水线（北美健身房大耳罩研究）

> 最后更新：2026-10-08（需求二次对齐版）
> 每次继续项目前先看这份文档。

## 一、业务背景

耳机公司开拓北美市场，需要理解「在健身房戴头戴式耳机（over-ear/on-ear）」的北美用户的爽点和痛点。传统北美访谈招募贵、周期长，用 LLM 把招募→筛选→访谈→分析链路自动化、降成本。方法论来源：`访谈大纲-具体内容.md`（真实访谈项目的判断信号框架、用户归类维度）。

## 二、研究设计参数

| 参数 | 值 |
|---|---|
| 问卷池规模 | 预设 500 人（定向发送问卷链接） |
| 目标访谈量 | 20 人 |
| 单场时长 | 约 45 分钟，语音访谈 |
| 受访者奖励 | $100 等值（亚马逊礼品卡或耳机奖品） |
| 邀请策略 | 分批邀请（首批约 12 人，按接受率 60-80% 补发） |
| 访谈语言 | 英文；分析报告输出中文（引用保留英文原文） |
| 隐私合规 | 录音+文字为默认；录像需受访者单独勾选同意；问卷含录音同意声明 |

## 三、五环节流程

### 环节 1：问卷收集 + AI 初筛 【DSL 已生成，待飞书配置】
- 受访者（英文界面）填 14 项问卷 → LLM 按硬性标准初筛（≥2-3次/周训练、耳机≥$200、含力量训练、确实在健身房戴大耳罩、拥有大耳罩）→ 输出匹配分/标签/理由 → 写入飞书「问卷池」（21 个字段）→ 回复语含 $100 奖励说明
- 交付物：`workflow2_问卷收集与初筛.yml`

### 环节 2：研究员筛选 + 发邀请邮件 【未开始】
- 研究员（中文）输入筛选条件（消费水平、年龄、性别等）→ 工作流读问卷池 → LLM 选人 → Resend 发英文邀请邮件（含访谈链接、$100 奖励说明、录音同意提示）→ 更新表格「筛选状态/邀请状态」→ 支持分批邀请与补发

### 环节 3：AI 语音访谈 【未开始，双线方案】
- **主线（方案 B）**：浏览器语音识别（Web Speech API）→ Dify 对话应用（访谈大纲为 prompt）→ 浏览器 TTS 播报；全程录音 + 实时转写文字
- **Demo 线（方案 A）**：OpenAI Realtime API 独立 demo 页，验证体验差异
- 研究员预先上传/填写访谈大纲（关键问题、使用过程描述、痛点追问方向）
- 结束后文字稿自动调用环节 4 的 API

### 环节 4：单场访谈分析 【✅ 已跑通】
- 文字稿 + 研究员关键词 → 并行：代码节点词频统计 / LLM 用户画像提取 / LLM 关键词情感分析 / LLM 判断信号与归类 → 中文报告 + JSON（供环节 5 聚合）→ 结果存飞书「访谈分析库」
- 交付物：`workflow1_单场访谈分析.yml`

### 环节 5：综合报告 【未开始】
- 读全部单场 JSON → LLM 交叉统计：高频痛点、用户类型分布、优先级共识与分歧、换购机会池 → 综合访谈报告（中文）
